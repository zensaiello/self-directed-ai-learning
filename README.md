# Self-Directed Technical Learning

This repository documents a structured, hands-on approach to technical skill development across observability, infrastructure, and cloud-native tooling. Each sub-project is a purpose-built lab designed to build working knowledge through real implementation rather than tutorials or theory.

Labs are guided by research and structured learning plans, with working configurations, documented decisions, and real problems encountered and solved along the way.

A secondary goal is demonstrating practical AI collaboration — using AI to research, structure, and adapt learning content in real time rather than following static courses. A real-world example of purposeful prompting and human-AI partnership.

## Current Labs

- **grafana-observability-lab** — Building and operating the full Grafana LGTM stack (Loki, Grafana, Tempo, Mimir) from scratch on local infrastructure. Structured as a five-week program covering metrics, logs, traces, alerting, and long-term storage.
- **kubernetes-lab** — Kubernetes fundamentals and cluster management. Running in parallel with the observability track.

## Approach

Every lab starts from scratch, runs on real infrastructure, and documents not just what was built but why decisions were made and what went wrong. The goal is portfolio-grade work that reflects how I actually think and build, not polished demos.
